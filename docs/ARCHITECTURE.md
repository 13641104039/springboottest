### 1.2 技术选型

| 层次 | 技术 | 说明 |

| 支付 | 支付宝/微信支付 | 第三方支付 |

## 2. 模块设计

### 2.1 用户模块

**功能**:
- 用户注册、登录、登出
- 用户信息管理
- 角色权限管理
- 实名认证

**核心类**:
- `User` - 用户实体
- `UserService` - 用户服务
- `AuthController` - 认证控制器
- `JwtTokenProvider` - JWT工具类

**数据流**:
```
用户请求 → AuthController → UserService → UserMapper → MySQL
                ↓
         JwtTokenProvider (生成Token)
                ↓
         返回Token给客户端
```

### 2.2 房源模块

**功能**:
- 房源发布、编辑、删除
- 房源搜索、筛选
- 房源详情展示
- 房源审核

**核心类**:
- `Property` - 房源实体
- `PropertyService` - 房源服务
- `PropertyController` - 房源控制器
- `SearchService` - 搜索服务

**搜索流程**:
```
搜索请求 → PropertyController → SearchService
                                      ↓
                              Elasticsearch查询
                                      ↓
                              返回搜索结果
                                      ↓
                              Redis缓存结果
```

### 2.3 预约模块

**功能**:
- 创建预约
- 预约确认/取消
- 预约查询
- 预约提醒

**核心类**:
- `Appointment` - 预约实体
- `AppointmentService` - 预约服务
- `AppointmentController` - 预约控制器

**预约流程**:
```
创建预约 → AppointmentController → AppointmentService
                                          ↓
                                  检查时间冲突(Redis锁)
                                          ↓
                                    保存到MySQL
                                          ↓
                                  发送MQ消息(提醒)
```

### 2.4 订单模块

**功能**:
- 创建订单
- 订单支付
- 订单查询
- 订单退款

**核心类**:
- `Order` - 订单实体
- `OrderService` - 订单服务
- `OrderController` - 订单控制器
- `PaymentService` - 支付服务

**订单流程**:
```
创建订单 → OrderController → OrderService → 生成订单号
                                                ↓
                                          保存到MySQL
                                                ↓
                                    调用PaymentService
                                                ↓
                                    调用第三方支付API
                                                ↓
                                      返回支付链接
                                                ↓
                                    用户完成支付
                                                ↓
                                    支付回调处理
                                                ↓
                                    更新订单状态
```

### 2.5 推荐模块

**功能**:
- 基于用户行为的推荐
- 相似房源推荐
- 热门房源推荐

**核心类**:
- `RecommendationService` - 推荐服务
- `UserBehaviorService` - 用户行为服务

**推荐算法**:
```
用户行为 → UserBehaviorService → 记录到MySQL
                                      ↓
                          RecommendationService
                                      ↓
                          协同过滤算法计算
                                      ↓
                          Redis缓存推荐结果
                                      ↓
                          返回推荐列表
```

## 4. 缓存设计

### 4.1 缓存策略

| 数据类型 | 缓存时间 | 更新策略 |
|---------|---------|---------|
| 用户信息 | 30分钟 | 主动更新 |
| 房源详情 | 1小时 | 主动更新 |
| 搜索结果 | 10分钟 | 定时刷新 |
| 推荐结果 | 1小时 | 定时刷新 |
| 热门房源 | 30分钟 | 定时刷新 |

### 4.2 缓存Key设计

```
user:{userId}                    # 用户信息
property:{propertyId}            # 房源详情
property:list:{page}:{size}      # 房源列表
search:{keyword}:{filters}       # 搜索结果
recommend:{userId}               # 推荐结果
hot:properties                   # 热门房源
```

## 5. 安全设计

### 5.1 认证流程

```
1. 用户登录 → 验证用户名密码
2. 生成JWT Token
3. 返回Token给客户端
4. 客户端请求携带Token
5. JwtAuthenticationFilter验证Token
6. 提取用户信息
7. 设置SecurityContext
8. 执行业务逻辑
```

### 5.2 权限控制

**角色权限矩阵**:

| 功能 | USER | LANDLORD | ADMIN |
|------|------|----------|-------|
| 浏览房源 | ✓ | ✓ | ✓ |
| 预约看房 | ✓ | ✗ | ✓ |
| 发布房源 | ✗ | ✓ | ✓ |
| 审核房源 | ✗ | ✗ | ✓ |
| 用户管理 | ✗ | ✗ | ✓ |

### 5.3 数据安全

- **敏感数据加密**: 密码使用BCrypt加密
- **数据脱敏**: 身份证号、手机号部分隐藏
- **SQL注入防护**: 使用MyBatis参数化查询
- **XSS防护**: 前端输入验证，后端HTML转义
- **CSRF防护**: Spring Security CSRF Token

## 6. 性能优化

### 6.1 数据库优化

- **索引优化**: 为高频查询字段建立索引
- **分页查询**: 使用MyBatis Plus分页插件
- **读写分离**: 主从复制，读写分离
- **连接池**: HikariCP连接池

### 6.2 缓存优化

- **多级缓存**: 本地缓存 + Redis缓存
- **缓存预热**: 系统启动时加载热点数据
- **缓存穿透**: 布隆过滤器
- **缓存雪崩**: 随机过期时间
- **缓存击穿**: 分布式锁

### 6.3 搜索优化

- **Elasticsearch**: 全文搜索引擎
- **搜索建议**: 自动补全
- **搜索高亮**: 关键词高亮
- **搜索缓存**: Redis缓存搜索结果

### 6.4 前端优化

- **代码分割**: 路由懒加载
- **图片优化**: 懒加载、压缩、WebP格式
- **CDN加速**: 静态资源CDN
- **Gzip压缩**: 服务器Gzip压缩

## 11. 总结

本系统采用前后端分离架构，后端使用Spring Boot构建RESTful API，前端使用Vue 3构建SPA应用。通过合理的模块划分、缓存设计、安全控制，实现了一个功能完整、性能优秀、安全可靠的高端公寓租赁管理系统。

系统具有良好的扩展性，可以根据业务需求进行水平扩展和垂直扩展，未来可以演进为微服务架构。
