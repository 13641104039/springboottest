# 高端公寓前端项目

## 技术栈
- Vue 3 + TypeScript
- Vite
- Element Plus
- Pinia
- Vue Router
- Axios
- ECharts
- 高德地图

## 安装依赖
```bash
npm install
```

## 开发
```bash
npm run dev
```

## 构建
```bash
npm run build
```

## 项目结构
```
src/
├── views/          # 页面
├── components/     # 组件
├── router/         # 路由
├── store/          # 状态管理
├── api/            # API接口
├── utils/          # 工具函数
└── main.ts         # 入口文件
```
